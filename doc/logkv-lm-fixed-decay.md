## 完了結果と解釈

**学習可能版はlossがわずかに良いが、生成の優劣は条件で入れ替わる。
固定減衰で再学習しても低温の語句・話題反復は解消しなかった。**
減衰を弱めた学習可能版は圧縮記憶へのattentionを増やすが、この調整だけでは生成の安定性は決まらない。

### Loss：差は小さい

同じ128例・212,943教師tokenに対する結果。全体lossはtoken数で重み付けした平均。

| 指標 | 固定減衰 | 学習可能減衰 |
|---|---:|---:|
| 最終rank0訓練EMA | 3.52558 | 3.52179 |
| 未消費例のloss | 3.62275 | **3.61796** |
| Perplexity | 37.44 | **37.26** |
| Wikipedia ja loss | 3.26093 | **3.25097** |
| Wikipedia en loss | 3.40793 | **3.40195** |
| cc100-ja loss | 3.47183 | **3.46778** |
| MiniPile loss | **4.33201** | 4.33264 |

学習可能版の全体loss改善は0.00479 nats/token、PPLの相対改善は約0.48%。
4ソース中3つで学習可能版が良いが、MiniPileでは固定版がごく僅かに良い。
訓練EMA曲線はほぼ重なり、学習進行に大きな差はない。
単一初期化seed・小さい評価集合であり、例別loss分散も未保存のため有意差は判定していない。

前回の「学習可能版のβだけをlog(4)へ戻す」lossは3.63179だった。
今回、固定減衰で最初から学習すると3.62275まで戻ったので、推論時の係数変更で生じた差の一部は
他の重みの適応で埋まる。推論時リセットによる悪化量0.01383を、そのまま固定学習の損失と解釈してはならない。

![訓練EMAと圧縮レベルattentionの比較](experiments/logkv-lm-fixed-decay-20260916/results/comparison.png)

### 生成：固定減衰にも同じ種類の反復が残る

各セルは **固定 / 学習可能**。bigram異なり率は生成文末尾1/4の文字bigramで、高いほど多様。
「<0.5」は記述用の反復指標であり、正確さや意味の整合性を測るものではない。

| 最大新規token | temperature | 件数/モデル | EOS | 平均長 | 末尾bigram異なり率 | 同率<0.5 |
|---:|---:|---:|---:|---:|---:|---:|
| 1024 | 0.7 | 9 | 4 / 4 | 705.9 / 674.2 | 0.539 / 0.461 | **4 / 4** |
| 1024 | 1.0 | 9 | 8 / 6 | 374.8 / 489.1 | 0.855 / 0.852 | **0 / 0** |
| 4096 | 0.7 | 3 | 2 / 3 | 2148.7 / 1487.7 | 0.447 / 0.547 | **2 / 1** |

1024上限・temperature0.7では平均異なり率は固定版が高いが、強い反復を示す件数は同じ。
同じprompt/seedで固定だけが閾値を下回るケースが2件、学習可能だけが下回るケースも2件あり、
一方が一貫して改善する関係ではない。平均だけでなく原文も確認した。

固定版には国名を並べ続ける例、同じ「住宅ローン控除」の句を繰り返す例、
「セキュリティソフトウェア」「宇宙飛行士」へ話題が固定される例が残る。
学習可能版で見られた地名・宇宙関連語の反復と同種で、単一tokenの連打だけではない。
したがって、少なくとも今回の2本では「固定log(4)に戻せば反復がなくなる」とは言えない。
一方で、学習可能化が反復を改善したという一貫した証拠もない。

temperature1.0では両方ともこの強い反復指標は0/9。固定版はEOSが多く平均長が短いが、
17〜18tokenで終わる例もあるため、終了率の高さを長文生成の良さと同一視しない。
両版で事実や話題の混同は残り、文章の多様性と内容の正しさは別である。

4096上限は両モデルとも1024上限の同じseed0のprefixと一致し、独立の追加3seedではない。

| prompt（seed0/temp0.7） | 固定版の長さ・終了 | 学習可能版の長さ・終了 | 観察 |
|---|---|---|---|
| 日本の首都は | 2332、EOS | 377、EOS | 固定は国名列の反復。学習可能は短く終わるが内容は不整合 |
| 昔々あるところに | 4096、上限 | 4068、EOS | 両方とも長い地名反復。末尾異なり率0.054 / 0.060 |
| 人工知能とは | 18、EOS | 18、EOS | token列も同じ短文。長文の検証にはならない |

**固定版・学習可能版のどちらも、良好な長文外挿を達成したとは評価しない。**

### ヘッド：参照先の分化は固定版にもあり、学習可能版では圧縮側への割合が増す

両モデルとも同じ128例の有効query位置だけを集計した。計64,338 query/ヘッド。
自己スロット、L0（元token）、L1（4token単位）、L2以上（16token単位以上）の確率質量を比較する。
query数で重み付け後、全層・ヘッドを等しく平均した値は以下。

| 参照先 | 固定 | 学習可能 |
|---|---:|---:|
| 自己スロット | 30.60% | 28.55% |
| L0 | 26.91% | 24.86% |
| L1 | 18.36% | 18.42% |
| L2以上 | **24.12%** | **28.17%** |

L2以上への割合は学習可能版で+4.05 percentage points。
全16層のヘッド平均で増え、個々のヘッドでも124/128で増えた。
一方、対応する層・ヘッド番号のL2以上の割合の相関は0.987と高い。
最も強く圧縮側を見る上位3ヘッドも、両方で第7層H1、第9層H5、第5層H7の順に一致する。

| ヘッド（1始まり） | 固定のL2以上 | 学習可能のL2以上 |
|---|---:|---:|
| 第7層H1 | 67.75% | 73.21% |
| 第9層H5 | 67.06% | 72.59% |
| 第5層H7 | 64.13% | 67.93% |

この同じ初期化・データ順の比較では、学習可能減衰がゼロから別の役割分担を作ったというより、
**固定版にもある局所／圧縮参照の分化を保ちつつ、圧縮側に配分を増やす**という解釈が合う。
学習可能版のβは全て正（平均1.0215、固定は1.3863）で、負の係数はこの変化の必須条件ではない。
ただし他の全重みも別々に更新されているので、attention差をβの直接効果だけに帰属させることはできない。
同じヘッド番号の相関も、異なる初期化に対する普遍的な役割を証明するものではない。

第1層の自己スロット割合は固定93.57%、学習可能92.83%。中間層ほど圧縮側が多い形は共通する。
自己スロットの入力にもCausalConvが含まれるため、自己参照優勢を過去の不使用と解釈しない。
また、これはgate・出力射影前のsoftmax質量で、最終logitへの因果的寄与や生成中の反復機序そのものではない。

### 方針への示唆

今回、学習可能減衰には小さいloss上の利点と圧縮記憶への参照増加があった。
ただし反復対策としては不十分で、固定減衰が明確に安全な生成を保証するという結果でもなかった。
学習可能減衰を候補に残しつつ、反復は減衰選択だけで解決する課題とみなさずに切り分けるのが妥当。
主効果は依然小さく、単一seedと既存autocast精度差を含むため、標準変更は行っていない。

次の小さい診断候補は、反復が始まる前後で生成中のattention配分とtoken分布を追い、
同じ保存checkpointのβだけを変更した場合にループから抜けるかを調べること。
今回の自然文上の平均attentionから反復原因を断定することは避ける。
これは候補であり、新たな学習・GPU評価は開始していない。

## 比較条件

| 項目 | 固定減衰（今回） | 学習可能減衰（完了済み対照） |
|---|---|---|
| 凍結ソース | 前回と同一の`ce360e3`の7ファイル | 同左 |
| モデル | d1024/H8/ff3072/16層/C4、context2048 | 同左 |
| 構造 | 重複なし、phaseなし、CausalConv幅4、gate/self slotあり | 同左 |
| logit補正 | `−i log(4)` | `−i β[layer,head]`、β初期値log(4) |
| パラメータ数 | 327,392,256 | 327,392,384（+128） |
| 学習 | 5,000 optimizer steps、新規seed0、6GPU×batch4×蓄積1 | 同左 |
| データ | 同じpretrain mmap、同じDistributedSampler順序、120,000 rows | 同左 |
| 最適化 | Muon＋AdamW、lr2e-4、warmup1000、clip1 | 同左 |
| 精度 | fp32 master＋bf16 autocast、評価も同じ | 同左 |
| 保存・生成 | 1000 stepsごと、5個のcheckpoint保持、固定日本語3prompt | 同左 |
| 周期サンプルRNG | `12345+step`、訓練RNGに影響させない | 同左 |

`--learnable-decay`を指定せず、元の標準固定減衰を用いる。その他のCLI設定差はrun名のみ。
前回と同じ未学習初期化をCPUで再構成し、学習可能版／固定版の**共通する全tensorが完全一致**する
ことを確認した。実際の固定版初期重みも同じfingerprintに一致することを各run開始時に検証する。
学習済み重みの転移や前回runの再開ではない。
[初期化照合](experiments/logkv-lm-fixed-decay-20260916/initialization_audit.json)。

**比較の範囲**：元の固定バイアスはPython scalar、学習可能バイアスはfp32 tensorで、
bf16 autocast下のlogit加算の精度も異なる。既存実装を変えずに比較するため、結果はこの数値計算差を
含むオプション全体の差。係数学習だけの効果を厳密に分離した実験ではない。
学習可能版の推論時βリセットよりは、固定減衰に適応する再学習を含めた対照になる。

## 同じ入力・条件での評価

- 前回と同じ未消費packed row 128例（4ソース各32例）、212,943教師tokenのloss/PPL。
  入力・教師のハッシュ、行index、PADマスクが一致することを確認する。
  行単位で訓練と分離しているが、文書単位の重複除去をした外部評価セットではない。
- 日本語3prompt×seed0–2×temperature0.7/1.0、最大1024新規tokenの18件。
  同じ3promptのseed0/temp0.7を最大4096新規tokenまで延長する3件。合計21件。
  top_p=0.9、repetition_penalty=1、EOSで停止。生成tokenと全文を保存する。
- EOS、長さ、末尾1/4の文字bigram異なり率、token4gram反復率、同一token連続数を比較する。
  同じseedでもモデルが違えば生成は分岐する。短いEOSや指標だけで生成品質を判断しない。
- attentionは前回の修正後と同じ128例・最後の最大512**有効query位置**を使う。
  入力が非PADかつ教師が非maskedの位置のみ、計64,338 query/ヘッド。
  全層・ヘッドのレベル別／自己スロットへの質量を比較する。gate・出力射影前の値で、
  最終出力への因果的寄与を直接表すものではない。
- 全5000-step loss/grad/lr、5個の保存checkpoint、初期化、生成指標と原文を監査する。
  訓練loss/EMAは両方ともrank0の値で、6GPU平均ではない。単一seedの比較。

前回のPADを含んだ旧`results/attention_mass.json`は比較に使用しない。
`analysis/attention_valid.json`の修正済み対照を使い、今回も観測器の有無で出力がbit一致することを確認する。
