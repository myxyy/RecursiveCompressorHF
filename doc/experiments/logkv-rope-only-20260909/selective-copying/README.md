# selective-copying段階の評価結果

CPU集計と保存結果の照合を完了。[確認記録](review.json)。2 GPU以内でタスクを分けて実行。全体8時間の上限を維持し、16M評価・追加アブレーションは開始しない。

[条件と実装](../../../logkv-rope-only.md)。各方式はphase_emb=false、固定M=10、50,000 steps、各T256例、1学習seed。
全33評価点は[metrics.csv](metrics.csv)、実行情報と検証結果は[summary.json](summary.json)。
