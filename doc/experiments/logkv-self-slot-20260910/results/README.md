## 確認後の解釈

自己スロット除去は全体として悪化した。T131072のbest/finalは175/256・2/256（対照はいずれも247/256）。
元の自己ありbestでは、固定16例のT49152で9桁目を誤った13例すべてが10桁目の値を出力した。
T49153では8桁目の11誤答すべてが9桁目の値で、どちらも絶対位置49170に対応する。
T131072の元の9誤答をfp32で再評価するとbestは3例回復・6例残存、finalは全9例残存。
