## 逆方向の介入

良好Tの同じ回答桁に、不良Tの中間表現を移植すると、bestの検証32例で以下の悪化が起きた。

| 良好T・回答桁 | 介入なし | 第1層head8を不良値に | 第2層gateを不良値に | 第2層gate前出力を不良値に |
|---|---:|---:|---:|---:|
| 32768・9桁目 | 32/32 | 15/32 | 18/32 | 32/32 |
| 32769・8桁目 | 32/32 | 17/32 | 17/32 | 32/32 |

対照head1の逆方向置換は両Tとも32/32のままだった。
この双方向の変化から、第1層head8と第2層gateの値は、この誤答に因果的に関わると考えられる。
ただし、すべての影響がgateだけを通るという完全な媒介関係までは検証していない。

## 中間表現と解釈

bf16では、head8出力移植と記憶slotのRoPE変更が、best/final・発見/検証・両Tすべてで
同じ全10位置のlogitを生成した。best fp32でも両介入の最大logit差は4.77×10⁻⁶以下だった。
空白slot除外はbf16/fp32とも全条件で介入なしのlogitと一致した。
このhead・この位置に限れば、追加空白slot c2の競合より、記憶slotへのRoPE位相の変化が有力である。
空白slotが他のhead・位置でも常に無関係という意味ではない。

best bf16のT49152・検証32例では、head8またはRoPEの介入により、
第2層gateのsigmoid前logitの良好Tからの距離（例平均L2）が約41.98から0.01へ下がった。
第2層gateだけを移植すると、第2層Queryは不良時のままでも誤答が回復した。
第2層のgate前出力だけを移植しても回復しなかったことと合わせると、
**第1層head8の位相依存 → 第2層のgateを含む桁選択 → 出力のずれ**という経路を支持する。
L2距離自体に正しさの尺度という意味はなく、同じcheckpoint・同じ特徴空間での参考値である。

記憶を含むlevel7 slotのK/Vは対照T間で全層・全例について一致していた。
この2つのTでの差を、当該slotの保存内容が変わったことだけに帰すことはできない。
ただし、圧縮された表現が元から持つ弱点や、他のslot・局所履歴の影響は除外しない。
第2層FFN出力の移植でも回復したが、下流の修復であるためFFNが根本原因だとは断定しない。

## この結果で未解決のこと

- RoPEの−3を−2にする操作は、特定head・階層・回答位置に対する診断。一般的に正しい位置表現への修正ではない。
- 対照Tからの出力移植も、元の10桁が同じ別文脈の中間値を使う反実仮想介入であり、通常推論の機能ではない。
- T131072で残っていた9誤答、短距離の誤答、他の階層や位置、別学習seed、Selectiveは今回の介入評価の対象外。
- 次のモデル修正を選ぶには、上位階層のRoPEによる変化がgateの桁選択へ混入しにくい構成を、広いTで再検証する必要がある。

元モデルの実装と重みは変更していない。修正版モデルでの長距離完全一致や16M成功を主張しない。
追加GPU実験を起動せず、mainマージも保留している。

## 介入内容

主比較はT49152の9桁目（0始まりの絶対位置49170）と、対応するT32768の9桁目。
確認比較はT49153の8桁目（同じ絶対位置49170）と、T32769の8桁目。
後者もT差を4^7に揃え、回答桁と下位階層の位相を揃える。
以下でhead8/head1は1始まりの番号。すべて**指定した1回答位置だけ**に介入する。
介入より前の回答は不変を必須検証にする。介入後の回答は、変化した過去を参照するため変わり得る。

| ラベル | 操作 |
|---|---|
| none | 介入なし |
| head8 | 第1層head8のgate適用前のattention出力を、同じ記憶・回答桁の対照Tの値に置換 |
| head1 | 同じ操作をhead1に行う対照。無関係なheadだとは仮定しない |
| l1_block | 第1層block出力全体を対照値に置換 |
| phase | 第1層head8・level7・記憶slotだけRoPEを−3→−2にする |
| mask | 第1層head8・level7の追加空白slot c2だけをsoftmaxから外す |
| phase_mask | phaseとmaskの両方 |
| l2_gate | 第2層gateのsigmoid前の全特徴を対照値に置換 |
| l2_raw | 第2層の全headのgate適用前出力を対照値に置換 |
| l2_raw_gate | 第2層のgateとgate適用前出力の両方を置換 |
| l2_ffn | 第2層FFNの出力branchを対照値に置換。残差は対象Tのものを維持 |

head8/head1/l1_block/l2_gate/l2_raw/l2_raw_gate/l2_ffnは、逆方向（不良Tの値を対照Tへ）も実施する。
同じ実行の値を戻すsham置換と、同じRoPE −3を適用し直すshamを設け、logitの完全一致を確認する。
phase/maskはhead8だけの操作であり、全headや全位置でのRoPE変更ではない。

bf16ではT49144〜49160も介入なしで走査する。fp32ではT49151〜49153と対応する対照Tを評価する。
全体で350条件（bf16各126、fp32が98）。各条件の標本数は発見16または検証32。
完全一致・対象桁正答・正解と最大競合のlogit差・次桁とのlogit差・改善例数と悪化例数を記録する。
次桁とのlogit差は隣接桁の値が同じ例では0になり、位置選択の判定には使えない。
第2層のQuery、gate、gate後head寄与、attention branch、FFN branch、block出力も保存する。

## 検証と制約

CPUでは独立した全スロットsoftmaxとscore介入を照合し、GPU bf16でも計測有無とshamの出力一致を検証する。
本評価では既存16列の予測再現、prefix KVの不変性、対照T間の記憶slot K/V一致、
checkpoint SHA256不変、介入前回答不変を必須チェックにする。
長い共通prefixは8192単位の同じ処理で計算し、回答を含む最後のchunkだけ再実行する。

これは診断のための反実仮想介入であり、対照Tの中間値を使って改善しても実運用可能な修正とはいえない。
head8による改善だけで「内部時計」を証明したとはしない。
第2層FFN branchの置換による改善も、そのFFNが根本原因だとの証明にはならない。

全GPU実行と集計の上限は2時間。最大3GPU、失敗時はほかのworkerも停止し、自動再試行しない。
prefix再利用により当初の1〜2時間見込みより短縮できる可能性がある。各workerで実時間を記録する。
新規学習・Selective・16M評価・mainマージは実施しない。
